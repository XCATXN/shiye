# 拾页 · 聊天存档

把一条 AI 聊天保存在本机，整理成便于阅读、检索和继续总结的 TXT / JSON。

**拾页（Shiye）**是面向 Chrome / Edge 的开源浏览器扩展，适合长篇创作、学习笔记和技术讨论的个人归档。它保存实际取得的原文、来源及校验信息，再合并分页、去重、区分正文与辅助记录。它不会替你生成总结，也不会补写缺失内容。

**Shiye is a local-first Chrome/Edge extension for archiving a single AI conversation.** It preserves captured responses, validates ordering, and exports readable TXT/JSON with explicit coverage limits. It is not an official account export tool.

当前版本：**0.9.0** · [MIT 许可证](LICENSE) · [隐私与权限](PRIVACY.md) · [代码结构](ARCHITECTURE.md)

## 可以做什么

- 从浏览器工具栏打开原生侧栏，采集当前选定的聊天。
- 保存原始响应、校验值和采集进度；支持暂停、继续、离线重新校验适用的会话记录。
- 合并分页、按来源顺序排列、去除重复，并导出 TXT / 整理 JSON；原始 JSON 始终可以单独下载。
- 选择正文与附件引用，或更多记录类型；提供首尾预览、本地空间统计和记录删除。
- 从工具栏侧栏启动的采集可在切换标签、关闭侧栏后继续；保持原聊天标签打开且不刷新、不跳转。
- 点击“关闭插件”保存检查点并休眠；再次点击工具栏图标唤醒，不自动恢复暂停任务。

## 平台与采集范围

| 平台 | 默认方式 | 当前边界 |
| --- | --- | --- |
| ChatGPT | 当前路线的会话分页数据，无需滚动 | 不保证取得所有历史分支或服务端缺失正文 |
| Claude | 会话数据及父子关系，无需滚动 | 原始数据保留返回节点；阅读输出取当前路线 |
| DeepSeek | 历史消息及当前分支，无需滚动 | 思考等辅助片段在原始数据中保留，正文模式分开处理 |
| Gemini | 会话详情及游标分页，无需滚动 | 多候选回答的当前版本不明确时，正文整理停止提示 |
| 豆包、Kimi、千问、腾讯元宝 | 网页正文备用采集，可能滚动页面 | 明确标注网页来源，服务端历史完整性未验证 |

Claude、DeepSeek、Gemini 也可手动选择网页备用方式。旧记录继续采用原有方式，接口失败不会静默改成网页采集。

**采集结束不等于官方全量备份完整。** 隐藏分支、旧版本、被平台省略的正文和附件原文件可能不在结果中。附件只保留已取得的资料或引用，不会自动下载原文件。此项目与上述平台无官方隶属关系，网页内部接口变化可能导致适配失效。

## 安装

1. 下载本仓库的源码 ZIP 并解压，或下载 Releases 中的扩展安装包并解压。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”，点击“加载未打包的扩展程序”或“加载解压缩的扩展”。
4. **源码 ZIP 选择 `edge-extension` 文件夹；扩展安装包选择解压后的根文件夹。** 所选目录必须直接包含 `manifest.json`，不要选它里面的 `icons` 文件夹。
5. 将“拾页”固定到工具栏。在目标平台登录并打开已有聊天，待回复生成结束后，点击拾页图标。

运行扩展不需要构建工具、API Key 或额外服务器。请使用较新的 Chrome / Edge，并保留安装时选择的文件夹。

## 日常使用

点击“采集当前聊天”，完成后选择整理范围与 TXT / JSON 格式，再点击“整理并下载”。想保留审计依据时，同时下载“原始 JSON”。采集中遇到错误也可以先保存已取得的数据。

侧栏的 **×** 只关闭界面；**“关闭插件”**会停止采集和轮询并进入休眠。它不等于浏览器禁用或卸载扩展，也不承诺浏览器立即回收至零内存。原 F12 兼容入口仍保留，日常采集建议使用工具栏侧栏。

Chrome 与 Edge 的本地记录各自保存，不会自动同步。删除本地记录不删除平台聊天或已经下载的文件；清理扩展数据或卸载扩展可能使本地记录丢失，需要长期保留时请另行下载。

## 透明度与验证

本仓库公开扩展运行代码、离线整理工具、测试及打包脚本。扩展直接加载仓库中的本地 JavaScript / CSS，无远程脚本、开发者接收服务器或使用分析上报。登录凭据仅用于当前平台的读取，请参阅 [PRIVACY.md](PRIVACY.md)。

本次公开源码通过 **157 项 Node 回归测试和 36 项 Python 测试**。真实短聊天样本中，DeepSeek 的 3 轮 / 6 条消息、Gemini 的 4 轮 / 8 条消息通过原文、顺序和结束复核。**这些短样本未验证 Gemini 真实跨页、编辑候选及附件原文件。** 多页等边界另有合成测试，不能代替真实长聊天验收。

公开测试使用合成数据；私人聊天、账号凭据和个人验收档案不属于开源仓库。

## 开发与打包

需要 Node.js 22+ 和 Python 3.11+；运行测试时确保 `python` 在 PATH 中。除可选图标重建需要 Pillow 外，无需安装运行时依赖。

```bash
node --test test_core.cjs
python -m unittest discover -p "test_*.py"
python package_release.py 0.9.0
```

打包结果位于 `dist/`，包含扩展安装包与源码包。扩展安装包根目录直接包含 `manifest.json`。具体贡献要求见 [CONTRIBUTING.md](CONTRIBUTING.md)，历史变化见 [CHANGELOG.md](CHANGELOG.md)。

也可离线整理已下载的原始采集文件，输出目录必须尚不存在：

```bash
node organize_capture.cjs capture.json new-output-directory reading
```
